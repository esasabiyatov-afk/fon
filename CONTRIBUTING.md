# Как участвовать / Contributing

Fon — открытый проект (MIT). Можно делать свои версии (форки) и присылать правки в основной репозиторий.

## Сборка

Mac не нужен. Форкните репозиторий, включите **Actions**, сделайте push в `main` — workflow `.github/workflows/build.yml`
соберёт `Fon.ipa` (XcodeGen → xcodebuild без подписи) и выложит его в **Releases** вместе с `apps.json` для SideStore.
Проверка на устройстве — только руками, на настоящем iPhone/iPad.

## Правила кода

- Swift/UIKit, новые `.swift`-файлы в папке `Fon/` подхватываются автоматически; JS для страниц YouTube живёт строками в `Scripts.swift`
  (проверяйте `node --check`).
- **Визуальное не должно влиять на воспроизведение:** никаких выходов кадров/слоёв на треке ради красоты и живого размытия поверх анимированного фона.
- Пишите комментарии по-русски или по-английски — как удобнее.
- Карта кода — в `CLAUDE.md`.

## Pull request

1. Форк → ветка → правка → PR в `main`.
2. Коротко опишите, что и зачем поменяли и на каком устройстве/iOS проверяли.
3. Одна тема на PR.

## Баги и идеи

Откройте Issue по шаблону. Для багов приложите версию Fon (Настройки → внизу), модель устройства, iOS и скриншот или запись экрана.
